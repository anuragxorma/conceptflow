# Data Attribution

The `.cxt` files in this directory are derived from:

Nöhre, M., Dürrschnabel, D., Ganter, B., Stumme, G.  
*A Visual Benchmark of DimFlux: Comparison of Line Diagrams for Concept Lattices* (2026)  
https://doi.org/10.5281/zenodo.18936106

These datasets are used for testing and demonstrating the DimFlux layout integration.
