# FCA repository contexts

These formal contexts are copied from the FCA repository,
https://github.com/fcatools/contexts (fcarepository.org), which publishes them
under CC0 1.0 (public domain). Sources for each context are listed in
`../fca_repository.json`.

`conceptflow.datasets.load_context(name)` reads these copies;
`conceptflow.datasets.fetch_fca_repository(name)` downloads the current version.
